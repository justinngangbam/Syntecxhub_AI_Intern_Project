Syntecxhub AI Internship Projects
This repository contains the completed weekly tasks for the AI Internship program at Syntecxhub.

Project 1: Maze Solver using A* Search
Overview
Implementation of the A* search algorithm to find the shortest path in a grid environment.

Key Features
Grid Modeling: Represents the maze with start, goal, and obstacles using node structures.

Heuristic Search: Uses Manhattan distance to optimize pathfinding.

Path Reconstruction: Returns the shortest path or handles unreachable cases.

Visualization: Console-based rendering of the solved maze.

Project 2: Rule-Based Expert System
Overview
A forward-chaining inference engine utilizing if-then logic for diagnostic reasoning.

Key Features
Knowledge Base: Stores predefined rules and facts.

Forward Chaining: Infers new conclusions based on user input.

Multi-Step Inference: Chains rules together for complex deductions.

Reasoning Log: Tracks and displays the exact path of deduction.

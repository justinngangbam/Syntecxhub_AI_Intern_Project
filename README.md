Project 1: Maze Solver using A* Search
Overview
Implementation of the A* search algorithm to find the shortest path in a grid environment.

Key Features
Grid Modeling: Represents the maze with start, goal, and obstacles using node structures.

Heuristic Search: Uses Manhattan distance to optimize pathfinding.

Path Reconstruction: Returns the shortest path or handles unreachable cases.

Visualization: Console-based rendering of the solved maze.
